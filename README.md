# Password manager

This repo is based on the chapter _Build a Secure Local Password Manager_ from [Node.js Projects](https://www.oreilly.com/library/view/node-js-projects/9781098173135/),

The implementation here is different by adding

- Typescript.
- Tests.
- Clean architecture.
- Presentation layers:
  - console (as in the book)
  - REST API (with Nest.js)
