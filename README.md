# Password manager

This repo is based on the chapter _Build a Secure Local Password Manager_ from [Node.js Projects](https://www.oreilly.com/library/view/node-js-projects/9781098173135/) book.

The implementation here is different:

- Typescript,
- Clean architecture (\*),
- A different workflow for the console.

> (\*) _Clean architecture_ is an overkill for such a small project, but it is done only as an excercise.
